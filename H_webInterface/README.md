# Interfaz Web - Predicción de Demanda de Bicicletas

Interfaz web desarrollada con Streamlit para interactuar con la API de predicción de demanda.

## Características

- Ingreso manual de datos meteorológicos y temporales
- Visualización de predicciones de demanda
- Gráficos de tendencias y patrones
- Verificación de estado de la API

## Instalación

```bash
pip install -r requirements.txt
```

## Uso

```bash
streamlit run app.py
```

La interfaz estará disponible en `http://localhost:8501`
